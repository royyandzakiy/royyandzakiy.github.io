This is my [personal blog](https://royyandzakiy.com/), hosted on GitHub
Pages. The site is generated by ssg, a small static site generator in
`_ssg/` written in standard C++20, and deployed by GitHub
Actions (`.github/workflows/pages.yml`) on every push to `main`.

## Build

Needs CMake and a C++ compiler (g++ or clang++).

    $ cmake -S _ssg -B _ssg\build
    $ cmake --build _ssg\build
    $ ctest --test-dir _ssg\build   # optional: unit tests

## Source layout

A unity build: a platform file includes `engine/ssg.cpp`, which includes
the rest.

    _ssg/core/      base types, arenas, strings; the os_* interface; logging
    _ssg/parser/    front matter, Markdown, syntax highlighting
    _ssg/engine/    site model, page templates, build driver
    _ssg/platform/  main.cpp: os_* with <filesystem>, <fstream>, <chrono>
    _ssg/test/      unit tests (main_test.cpp is the test platform)

## Run locally

    $ _ssg\build\ssg -w                     # rebuild _site/ on every change
    $ python -m http.server 8000 -d _site   # in a second terminal

Open <http://localhost:8000>. Pages use absolute paths (`/css/...`),
so opening `_site/index.html` directly won't load the styles.

## Write a post

Add `_posts/YYYY-MM-DD-slug.markdown`:

    ---
    title: Hello, World
    layout: post
    tags: [meta]
    uuid: <any new UUID>
    ---

    Post body in Markdown.

Or write a draft whose first line is `# Title` and run
`_ssg/build/ssg -n draft.md` to file it into `_posts/` with today's date.
Post URLs are `/YYYY-MM-DD/slug/`, from the file name.

Tag pages and feeds are generated from the posts' front matter. Other
files are published as-is, except those starting with `_` or `.`.
